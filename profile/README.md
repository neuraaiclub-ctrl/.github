NEURA is a student-led coding club for people who'd rather build something than just read about it. Whether you're writing your first `for` loop or fine-tuning your fifth model, this is a place to learn in public, ship real projects, and find people who'll debug with you at 2am. We meet, we hack, we break things, we fix them — together.

<br/>

## 🧭 What We Stand On

| Principle                 | What It Means                                                        |
| ------------------------- | -------------------------------------------------------------------- |
| 🧠 **Learn by Building**  | Theory matters, but shipped projects teach faster than any tutorial. |
| 🤝 **Collaborate Openly** | Every repo, every doc, every idea — open for anyone to learn from.   |
| 🚀 **Ship Consistently**  | Small, working things beat big, unfinished ones.                     |
| 🔍 **Stay Curious**       | The best question in any session is "wait, why does this work?"      |

<br/>

## 🗂️ Explore With Us

| Domain                         | Focus                                                  |
| ------------------------------ | ------------------------------------------------------ |
| 🤖 **AI & Machine Learning**   | Neural nets, LLMs, and everything in between           |
| 🌐 **Web Development**         | Frontend, backend, and the glue that holds it together |
| 🔐 **Cybersecurity**           | CTFs, ethical hacking, and thinking like an attacker   |
| 🏆 **Competitive Programming** | DSA, contests, and sharpening problem-solving speed    |
| 🧩 **Open Source**             | Real contributions to real projects, from day one      |
